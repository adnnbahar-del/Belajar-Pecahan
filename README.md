# Media Pembelajaran Pecahan (Kelas VI SD)

Aplikasi media pembelajaran interaktif matematika materi Pecahan untuk siswa kelas VI Sekolah Dasar.

## 🚀 Fitur Utama
- **Materi Interaktif**: Visualisasi konsep pecahan, pecahan senilai, penyederhanaan, dan operasi hitung (penjumlahan, pengurangan, perkalian, pembagian).
- **Simulasi & Visual**: Representasi grafis pizza, balok pecahan, dan animasi interaktif.
- **Kuis & Game Edukasi**: Latihan soal interaktif dengan skor langsung dan evaluasi pemahaman siswa.
- **Dashboard Guru & Admin**: Pemantauan catatan perkembangan siswa, statistik belajar, dan rekapitulasi nilai.
- **Dukungan Audio & Video**: Media pembelajaran lengkap dengan penjelasan narasi dan video edukasi.

## 💻 Cara Menjalankan Secara Lokal

1. Buka terminal pada root direktori proyek:
   ```bash
   node server.js
   ```
   *(Atau cukup buka file `index.html` langsung di browser favorit Anda)*
2. Buka browser dan akses:
   - Aplikasi Siswa: [http://localhost:8080](http://localhost:8080)
   - Dashboard Admin: [http://localhost:8080/admin.html](http://localhost:8080/admin.html)
